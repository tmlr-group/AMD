# Anchor-based-Maximum-Discrepancy
Reproducibility code for AMD: Anchor-based Maximum Discrepancy for Relative Similarity Testing, presented in the Neurips 2025. 
This work is done by
- Zhijian Zhou (unimelb) zhijianzhou.ml@gmail.com
- Liuhua Peng (unimelb) liuhua.peng@unimelb.edu.au
- Xunye Tian (unimelb) xunyetian.ml@gmail.com
- Feng Liu (unimelb) fengliu.ml@gmail.com

## Requirements
- `python 3.9.0`

The packages in [`environment.yml`](.environment.yml) are required to run our tests and the ones we compare against.
